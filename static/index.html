Import from Excel

Drop an .xlsx or .csv file here, or

The first row should contain column headers (e.g. Name, Sex, Grade, Directorate/Agency, First Appointment Date, Current Appointment Date, Date Posted, Qualifications). Columns are matched automatically — you can correct the mapping before importing.

Backup & Restore

Back up the complete register — every field, for every record, and every attached passport photo and letter — to a single file you can store safely (e.g. on a shared drive, or a USB drive kept elsewhere). Larger registers with many attachments will produce a larger file, which may take a moment to prepare. Restoring will replace all data currently in the register with the contents of the backup file.

AI Staff Analysis Report

Analyzes the current establishment data — workforce composition, gender balance, staff/professional category mix, grade spread, and succession/retirement risk — using only aggregate counts, not individual names.

To generate the report automatically when you're online, this tool needs an Anthropic API key of your own (create one at console.anthropic.com). Usage is billed to your Anthropic account. The key is stored only in this browser on this computer — it is never sent anywhere except directly to Anthropic when you generate a report. If you skip this, you can still use the "Copy prompt" option to run the analysis manually through Claude or another AI assistant.
